# 🤖 AI Chatbot Using Flask & HuggingFace BlenderBot

This project is a simple AI-powered chatbot built using **Flask** and **HuggingFace Transformers** with the pre-trained model:

> ✅ facebook/blenderbot-400M-distill  

The chatbot receives user messages via an API and returns smart AI-generated responses.

---

## 🚀 Features

- REST API using Flask
- CORS enabled
- Uses HuggingFace Transformers
- Maintains conversation history
- Supports JSON-based requests
- Web interface supported using `index.html`

---

## 🛠️ Technologies Used

- Python
- Flask
- Flask-CORS
- Transformers (HuggingFace)
- BlenderBot Model
